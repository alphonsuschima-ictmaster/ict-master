# MODULE 5: FILE MANAGEMENT & WINDOWS BASICS

## 5.1 The File Hierarchy

Everything on a computer is organised in a hierarchy:

**Drive → Folder → Subfolder → File**

Example:
### Key Terms

- **File:** A single unit of stored data (document, photo, song, video).
- **Folder (Directory):** A container that holds files and other folders.
- **Root Directory:** The top-level of a drive (e.g. `C:\`).
- **Path:** The full address of a file, e.g. `C:\Users\Alphonsus\Documents\CV.docx`
- **File Extension:** The letters after the dot that tell you the type:
  - `.docx` — Word document
  - `.xlsx` — Excel spreadsheet
  - `.pptx` — PowerPoint presentation
  - `.pdf` — Portable Document Format
  - `.jpg` / `.png` — Image files
  - `.mp3` — Audio file
  - `.mp4` — Video file
  - `.exe` — Executable program (Windows)
  - `.zip` / `.rar` — Compressed archive

## 5.2 Common File Operations

| Operation | What It Does | Shortcut |
|---|---|---|
| Create | Make a new file/folder | Right-click → New |
| Rename | Change the file name | F2 |
| Copy | Duplicate the file (original stays) | Ctrl + C |
| Cut | Move the file (original is removed) | Ctrl + X |
| Paste | Place copied/cut file | Ctrl + V |
| Move | Cut + Paste to new location | Ctrl + X → Ctrl + V |
| Delete | Send to Recycle Bin | Delete key |
| Permanent Delete | Bypass Recycle Bin | Shift + Delete |
| Restore | Recover from Recycle Bin | Right-click → Restore |
| Properties | View size, type, date | Alt + Enter |

## 5.5 End-of-Module Quiz

**1. What is the shortcut for Undo?**
A) Ctrl + Y
B) Ctrl + Z
C) Ctrl + U
D) Ctrl + X

**2. Which file extension represents a Word document?**
A) .xlsx
B) .docx
C) .pptx
D) .pdf

**3. When you Ctrl + X a file, the original:**
A) Stays in place
B) Is removed and ready to paste elsewhere
C) Is permanently deleted
D) Is duplicated

**4. Win + E opens:**
A) Email
B) Explorer (File Manager)
C) Excel
D) Edge

**5. A folder inside another folder is called:**
A) A root
B) A subfolder
C) A drive
D) An extension

### ANSWER KEY

**1. B** — Ctrl + Z reverses your last action.

**2. B** — `.docx` is Microsoft Word's file format.

**3. B** — Cut removes the file from its current location and stores it for pasting.

**4. B** — Win + E is the universal shortcut for File Explorer.

**5. B** — Nested folders are called subfolders (or child folders).
