# MODULE 10: MASTER CBT REVISION & PRACTICE EXAM

## SECTION A: 50 SOLVED STANDARD EXAMINATION QUESTIONS

**1. What is a computer?**
An electronic device that accepts data, processes it, stores it, and produces information.

**2. Who is regarded as the father of the computer?**
Charles Babbage.

**3. What does CPU stand for?**
Central Processing Unit.

**4. What are the three parts of the CPU?**
Control Unit, Arithmetic Logic Unit, and Registers.

**5. Which part of the CPU performs calculations?**
The Arithmetic Logic Unit (ALU).

**6. What is the difference between data and information?**
Data is raw, unprocessed facts. Information is processed, meaningful data.

**7. Give four characteristics of a computer.**
Speed, accuracy, diligence, storage capacity (also versatility and automation).

**8. What does GIGO mean?**
Garbage In, Garbage Out — wrong input produces wrong output.

**9. List four input devices.**
Keyboard, mouse, scanner, microphone.

**10. List four output devices.**
Monitor, printer, speaker, projector.

**11. What are the two main types of memory?**
Primary memory (RAM, ROM) and secondary storage (HDD, SSD, USB).

**12. Differentiate between RAM and ROM.**
RAM is volatile, read/write, large. ROM is non-volatile, read-only, small.

**13. Which memory is used to store the BIOS?**
ROM.

**14. How many bits make one byte?**
8 bits.

**15. Arrange in ascending order: TB, KB, MB, GB.**
KB → MB → GB → TB.

**16. What is an operating system?**
System software that manages hardware and provides a platform for other programs.

**17. Give four examples of operating systems.**
Windows, macOS, Linux, Android (also iOS).

**18. What is the difference between system software and application software?**
System software manages the computer; application software helps the user perform specific tasks.

**19. Give three examples of application software.**
MS Word, MS Excel, Google Chrome.

**20. What is a utility program?**
A small program that maintains, optimises, or protects the computer.

**21. Give the shortcut for Copy, Paste, Cut, Undo.**
Ctrl+C, Ctrl+V, Ctrl+X, Ctrl+Z.

**22. What is a folder?**
A container that holds files and other folders.

**23. What is a file extension? Give two examples.**
Suffix after a dot indicating file type. Examples: .docx, .pdf, .jpg.

**24. What is a network?**
Two or more computers connected to share resources and data.

**25. Give four types of networks.**
PAN, LAN, MAN, WAN.

**26. What does LAN stand for?**
Local Area Network.

**27. Which network is the largest?**
WAN — the Internet is the largest WAN.

**28. Name four network topologies.**
Star, Bus, Ring, Mesh.

**29. Which topology uses a central hub?**
Star topology.

**30. Which topology is the most reliable?**
Mesh topology.

**31. What is the difference between a hub and a switch?**
A hub sends data to all devices; a switch sends data only to the intended device.

**32. What is a router?**
A device that connects different networks and routes data between them.

**33. What is a modem?**
A device that converts digital signals to analog (and back) for transmission over telephone/cable lines.

**34. What is the difference between the Internet and the WWW?**
The Internet is the global network of networks. The WWW is one service that runs on it.

**35. Who invented the WWW?**
Tim Berners-Lee (1989).

**36. Name three web browsers.**
Google Chrome, Mozilla Firefox, Microsoft Edge.

**37. Name three search engines.**
Google, Bing, Yahoo.

**38. What is cloud computing?**
Using computing services over the Internet instead of on your own device.

**39. Give two examples of cloud storage.**
Google Drive and Dropbox.

**40. What is a cell in Excel?**
The intersection of a row and a column.

**41. Which symbol starts every Excel formula?**
The equals sign `=`.

**42. What does `=SUM(A1:A5)` do?**
Adds the values in cells A1 through A5.

**43. What does the `IF` function do?**
Returns one value if a condition is true, another if it is false.

**44. What is the Rule of 6×6 in PowerPoint?**
Maximum 6 bullets per slide, 6 words per bullet.

**45. What is malware?**
Any malicious software designed to harm or exploit a system.

**46. Differentiate between a virus and a worm.**
A virus needs a host file and user action; a worm spreads on its own across networks.

**47. What is phishing?**
Tricking users into revealing sensitive information via fake messages or sites.

**48. Give three rules of digital safety.**
Use strong unique passwords; never share OTP; keep antivirus updated.

**49. What is two-factor authentication?**
A security method requiring two forms of verification — usually a password plus a code sent to your phone.

**50. What is ransomware?**
Malware that locks files and demands payment for their release.
