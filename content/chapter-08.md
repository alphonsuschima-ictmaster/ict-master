# MODULE 8: OFFICE PRODUCTIVITY SOFTWARE

## 8.1 Word Processing (MS Word)

**Word processing** means creating, editing, formatting, and printing text documents.

### Key Features
- **Text formatting:** Bold, Italic, Underline, font type, font size, colour.
- **Paragraph formatting:** Alignment (left, centre, right, justify), line spacing, indentation.
- **Page Setup:** Margins (top, bottom, left, right), orientation (portrait/landscape), paper size (A4, Letter).
- **Headers & Footers:** Text that appears at the top or bottom of every page (title, page number).
- **Insert:** Tables, pictures, charts, page breaks, symbols.
- **Review tools:** Spell check, grammar, word count, track changes.
- **Printing:** Ctrl + P; print preview before printing.

### Common Toolbar Icons and What They Do
- **B / I / U** — Bold / Italic / Underline
- **Ctrl + B / I / U** — Keyboard equivalents
- **File → Save As** — Save in different format (e.g. .docx or .pdf)

## 8.2 Spreadsheets (MS Excel)

**Spreadsheets** organise data in rows and columns and perform automatic calculations.

### Structure of a Spreadsheet
- **Column:** Vertical (A, B, C, ...)
- **Row:** Horizontal (1, 2, 3, ...)
- **Cell:** Intersection of a row and column (e.g. B3)
- **Cell Reference:** The address of a cell
- **Worksheet:** One sheet within a workbook
- **Workbook:** The whole file

### Essential Formulas and Functions

| Formula | What It Does | Example |
|---|---|---|
| `=SUM(A1:A10)` | Adds numbers | Adds cells A1 through A10 |
| `=AVERAGE(A1:A10)` | Finds the mean | Average of range |
| `=COUNT(A1:A10)` | Counts numeric cells | How many numbers |
| `=COUNTA(A1:A10)` | Counts non-empty cells | How many filled |
| `=MAX(A1:A10)` | Largest value | Highest score |
| `=MIN(A1:A10)` | Smallest value | Lowest score |
| `=IF(A1>=50,"Pass","Fail")` | Conditional result | Pass or Fail |

**Important:** Every formula begins with an equals sign `=`. Without it, Excel treats the entry as text.

## 8.3 Presentation Software (MS PowerPoint)

**PowerPoint** is used to create slideshows for presentations.

### Key Features
- **Slides:** Individual pages of the presentation.
- **Slide Master:** Controls the design of all slides at once.
- **Transitions:** Animation between slides.
- **Animations:** Effects applied to objects within a slide.
- **Notes pane:** Speaker notes not shown to the audience.
- **Slide Show (F5):** Runs the presentation fullscreen.

### Presentation Tips
- **One idea per slide** — don't crowd.
- **Rule of 6×6** — max 6 bullets, max 6 words per bullet.
- **Use visuals** — pictures, charts, diagrams.
- **Readable fonts** — minimum 24pt body text.
- **Consistent design** — same colours and fonts throughout.
- **Never read the slide** — use it as a support, not a script.

## 8.5 End-of-Module Quiz

**1. Every formula in Excel must begin with:**
A) +
B) =
C) #
D) @

**2. Which function adds a range of numbers?**
A) AVERAGE
B) SUM
C) MAX
D) IF

**3. In Excel, B3 refers to:**
A) Row B, Column 3
B) Column B, Row 3
C) The third cell in the file
D) A range

**4. Ctrl + P is used for:**
A) Paste
B) Print
C) Preview
D) Pause

**5. Which of these is a presentation software?**
A) Excel
B) Word
C) PowerPoint
D) Access

### ANSWER KEY

**1. B** — Formulas must start with `=`.

**2. B** — `=SUM()` adds a range.

**3. B** — Columns use letters (B), rows use numbers (3). B3 = column B, row 3.

**4. B** — Ctrl + P opens the Print dialog.

**5. C** — PowerPoint is the presentation tool.
