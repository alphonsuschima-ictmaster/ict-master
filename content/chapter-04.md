# MODULE 4: SOFTWARE SYSTEMS

## 4.1 What Is Software?

**Software** is a set of instructions, programs, and data that tells the hardware what to do. You cannot touch software — you can only see its results on screen.

**Hardware** = the body. **Software** = the mind.

---

## 4.2 The Four Main Types of Software

### 1. System Software

Software that manages and controls the hardware, and provides a platform for other software to run.

- **Operating Systems (OS):** The master program. Examples:
  - **Windows** (Microsoft) — most common on desktops
  - **macOS** (Apple) — for Mac computers
  - **Linux** — free, open-source (Ubuntu, Fedora, Debian)
  - **Android** — for smartphones and tablets
  - **iOS** — for iPhones and iPads
- **Device Drivers:** Small programs that allow the OS to communicate with hardware like printers, keyboards, and graphics cards.
- **Utility programs bundled with the OS:** File Explorer, Task Manager, Disk Defragmenter.

**Functions of an Operating System:**
- Process management
- Memory management
- File management
- Device management
- User interface (GUI or CLI)
- Security and access control

### 2. Application Software

Software designed to help the user perform specific tasks.

- **Word Processing:** MS Word, Google Docs
- **Spreadsheets:** MS Excel, Google Sheets
- **Presentations:** MS PowerPoint
- **Web Browsers:** Chrome, Firefox, Edge, Safari
- **Graphics Design:** Photoshop, CorelDRAW, Canva
- **Media Players:** VLC, Windows Media Player
- **Accounting:** QuickBooks, Sage
- **Banking apps:** GTWorld, Zenith Mobile

### 3. Utility Software

Small programs that help maintain, optimise, and protect the computer.

- **Antivirus:** Avast, Kaspersky, Norton, Windows Defender
- **Disk Cleanup:** Removes temporary and unnecessary files
- **Disk Defragmenter:** Reorganises HDD data for faster access
- **File Compression:** WinRAR, WinZip, 7-Zip
- **Backup Tools:** Windows Backup, Acronis
- **Firewall:** Blocks unauthorised network access

### 4. Programming Software

Tools developers use to write, test, and debug other software.

- **Code Editors / IDEs:** VS Code, Eclipse, NetBeans, PyCharm
- **Compilers & Interpreters:** Convert source code into machine code
- **Debuggers:** Help find and fix errors
- **Languages:** Python, Java, C++, JavaScript, PHP, Kotlin

## 4.4 End-of-Module Quiz

**1. Which of the following is system software?**
A) MS Word
B) Windows 11
C) Photoshop
D) VLC Player

**2. Antivirus software is best classified as:**
A) System software
B) Application software
C) Utility software
D) Programming software

**3. Which of these is NOT an operating system?**
A) Linux
B) Android
C) Oracle
D) macOS

**4. Device drivers are used to:**
A) Type documents
B) Enable communication between OS and hardware
C) Browse the internet
D) Compress files

**5. VS Code is an example of:**
A) Utility software
B) System software
C) Programming software
D) Application software

### ANSWER KEY

**1. B** — Windows is an operating system, which is system software.

**2. C** — Antivirus is utility software (maintenance/protection).

**3. C** — Oracle is a database system, not an operating system.

**4. B** — Drivers translate OS commands into signals hardware can understand.

**5. C** — VS Code is a code editor — programming software.
