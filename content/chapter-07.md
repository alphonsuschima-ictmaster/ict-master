# MODULE 7: INTERNET, WWW & WEB BROWSING

## 7.1 The Internet vs. The World Wide Web

Many people use these terms as if they mean the same thing. They do not.

- **The Internet** is the **global network of networks** — the physical infrastructure of cables, satellites, routers, and servers. It is the road.
- **The World Wide Web (WWW)** is **one service that runs on the Internet** — the system of linked web pages accessed through browsers. It is the cars on the road.

**Other services on the Internet (not the Web):**
- Email (SMTP)
- File Transfer (FTP)
- Voice/Video Calls (VoIP)
- Streaming (Netflix, YouTube)
- Online Gaming
- Instant Messaging (WhatsApp)

**Born:** The Internet began in 1969 as ARPANET (USA). The WWW was invented by **Tim Berners-Lee** in 1989 at CERN.

## 7.2 Web Browsers

A **web browser** is software that requests web pages from servers and displays them.

**Popular browsers:**
- **Google Chrome** — most used worldwide
- **Mozilla Firefox** — open-source, privacy-focused
- **Microsoft Edge** — default on Windows
- **Safari** — default on Apple devices
- **Opera** — with built-in VPN
- **Brave** — privacy-first

**Browser components:** Address bar, tabs, bookmarks, history, extensions, back/forward buttons.

---

## 7.3 Search Engines & Search Techniques

A **search engine** is a service that indexes the web and helps you find information.

**Popular search engines:** Google, Bing, Yahoo, DuckDuckGo, Yandex.

### Search Techniques (Very Important for CBT)

| Technique | Example | Effect |
|---|---|---|
| Plain keywords | `Nigerian universities` | General search |
| Quotation marks | `"Federal University Owerri"` | Exact phrase |
| Minus sign | `jaguar -car` | Exclude word |
| Site search | `site:jamb.gov.ng syllabus` | Search within a site |
| File type | `CBT guide filetype:pdf` | Only PDFs |
| Asterisk (wildcard) | `computer * definition` | Fills the gap |
| OR | `WAEC OR NECO` | Either term |

## 7.4 Cloud Services & Internet Applications

**Cloud computing** = using computing services (storage, software, processing) over the Internet instead of on your own device.

**Examples:**
- **Storage:** Google Drive, Dropbox, OneDrive, iCloud
- **Software:** Google Docs, Microsoft 365 Online, Canva
- **Email:** Gmail, Yahoo Mail, Outlook
- **E-learning:** Google Classroom, Khan Academy, Coursera
- **E-commerce:** Jumia, Konga, Amazon, PayPal
- **Social Media:** Facebook, X (Twitter), Instagram, TikTok, LinkedIn
- **Video Conferencing:** Zoom, Google Meet, Microsoft Teams
- **Payments:** Paystack, Flutterwave, PayPal, Opay

**Benefits of Cloud:** Access from anywhere, automatic backup, scalability, cost-effective.
**Risks:** Requires Internet, privacy concerns, dependence on provider.

## 7.6 End-of-Module Quiz

**1. Who invented the World Wide Web?**
A) Bill Gates
B) Tim Berners-Lee
C) Steve Jobs
D) Mark Zuckerberg

**2. The Internet and the WWW are:**
A) The same thing
B) The WWW is one service on the Internet
C) The Internet is a service on the WWW
D) Both are hardware

**3. Which is NOT a web browser?**
A) Chrome
B) Firefox
C) Google Search
D) Edge

**4. To search for an exact phrase, use:**
A) Asterisks
B) Quotation marks
C) Minus sign
D) Plus sign

**5. Google Drive is an example of:**
A) A search engine
B) Cloud storage
C) A web browser
D) An operating system

### ANSWER KEY

**1. B** — Tim Berners-Lee invented the WWW in 1989.

**2. B** — The Web is one of many services that run on the Internet.

**3. C** — Google Search is a search engine, not a browser.

**4. B** — Quotation marks force an exact phrase match.

**5. B** — Google Drive is cloud storage.
